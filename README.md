### 🧩 DupliCache — Multithreaded File Deduplication Tool

Chunk-based file deduplication engine built in C++17 to explore systems-level concurrency and storage concepts.

**What it demonstrates:** fixed-size chunking, SHA-256 fingerprinting, hash-map based duplicate detection, `std::thread` + mutex-guarded shared state, and single-threaded vs. multithreaded benchmarking with real, measured (not assumed) timing results.
